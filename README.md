# Sentiment Analysis on Twitter Data  
A Machine Learning Project by Sachini Hewahattage

This project builds a complete end‑to‑end sentiment analysis model using **TF‑IDF vectorization** and **Logistic Regression** to classify tweets as **Positive** or **Negative**.  
It demonstrates practical skills in data preprocessing, feature engineering, model training, evaluation, and saving ML artifacts for deployment.

---

## 📌 Project Overview

The goal of this project is to classify tweet text into two categories:

- **Positive**
- **Negative**

This is a classic NLP (Natural Language Processing) problem and a common real‑world use case in:

- Customer feedback analysis  
- Brand monitoring  
- Social media analytics  
- Product sentiment tracking
